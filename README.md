# Recommendation-according-to-BMI
This project calculates the Body Mass Index (BMI) based on user input (height and weight) and provides personalized health or lifestyle recommendations according to the BMI category.
💡 Features
BMI calculator using height and weight

Categorizes BMI (Underweight, Normal, Overweight, Obese)

Provides basic recommendations:

Diet and nutrition tips

Exercise suggestions

General health advice

📊 BMI Categories Used
Category	BMI Range (kg/m²)
Underweight	< 18.5
Normal weight	18.5 – 24.9
Overweight	25.0 – 29.9
Obese	30.0 and above

🚀 How It Works
User inputs height and weight

The program calculates the BMI

Based on the BMI, the program gives a recommendation
